# Autonomous Lead Enrichment Agent

A resilient Python agent for enriching company domains with public website intelligence. It uses Playwright for JavaScript-rendered pages, extracts focused page content instead of raw HTML, and optionally sends the cleaned context to an OpenAI model using a strict Pydantic schema.

## What it extracts

- Company name, description, industry, headquarters, and founded year
- Products and services
- Founders and leadership names with public profile URLs
- Public contact emails, phones, and social/company URLs
- Source URLs, crawl status, and per-domain timing

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[browser,dev]'
playwright install chromium
cp .env.example .env
```

Run the three assignment targets:

```bash
python -m lead_enrichment.cli postman.com supabase.com vapi.ai --output output.json
```

The command still completes without `OPENAI_API_KEY`: local metadata and contact extraction are used as a transparent fallback. With a key, the cleaned context is passed to the configured model for structured enrichment.

Useful options:

```bash
python -m lead_enrichment.cli --offline postman.com supabase.com vapi.ai
python -m lead_enrichment.cli postman.com --max-pages 4 --output output.json
```

`--offline` is useful for demos and tests. It skips network access and returns a valid, auditable result with an explicit status.

## Architecture

1. `BrowserCrawler` visits a domain homepage and same-domain candidate pages discovered from links and sitemap-like keywords.
2. `clean_html` removes scripts, styles, SVGs, navigation, footers, and repeated whitespace before truncating content.
3. `OpenAIExtractor` requests a JSON-schema response through Pydantic. A local extractor is used when credentials are absent or the provider fails.
4. `EnrichmentPipeline` isolates failures per domain and records status, errors, sources, and timing rather than aborting the batch.
